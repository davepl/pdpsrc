# Complete application deployed to 192.168.1.29

Deployment date: September 21, 2026. Source application: 192.168.1.26.

The target previously served the older static homepage. It is running 2.11BSD
patch 498, kernel MENTEC #9, with the existing `www` account (uid 80, gid 10),
`/home/www` document root, and HTTP launched through inetd. Its HTTP server
binary matched the preserved original server exactly and was retained.

## Installation

- Confirmed the live `.26` homepage, `webtop.c`, `webtop-cgi.c`,
  `visit-counter.c`, and Makefile matched this repository.
- Archived the original `.29` website, server binary, inetd configuration,
  services file, and startup file before installation; copied the archive
  off the PDP.
- Uploaded the complete source bundle to `/usr/src/local/webtop-source.tar`
  and extracted it into `/usr/src/local/webtop`. Staging used `/usr` because
  the approximately 3.9 MiB bundle would nearly fill the root filesystem.
- Ran `make clean`, `make`, and `make install` on the target. Both build and
  installation completed successfully. The sampler was compiled with the
  target's headers and separate instruction/data space.
- Installed the red-and-gold page, webtop, visitor counter, photo, and linked
  TMOG banner. No counter existed on `.29`, so it received an independent
  total initialized at zero; `.26`'s count was not copied or changed.
- Changed only the inetd invocation in `/etc/rc` to
  `/usr/sbin/inetd -R 1000`, following `config/README.inetd.md`. Checked shell
  syntax, retained root ownership/mode 644, and restarted inetd with that rate.
  The original startup file is `/etc/rc.before-webtop-20260921`.
- The public proxy configuration was not changed by this LAN deployment.

## Verification

Serial HTTP requests confirmed exact repository matches for the homepage
(15,234 bytes), restored photo (101,511 bytes), and TMOG banner (167,696 bytes).
The webtop CGI returned the target's live processes and a snapshot-age header;
two immediate requests shared a frame, and a request after the cache interval
returned a different frame. The counter CGI advanced zero to one, and static
reads and a browser refresh kept the total at one. That first visit is the
deployment smoke test. Browser inspection confirmed the visitor masthead,
webtop panel, and TMOG banner below it. Both source and minified-page visitor
tests passed, including reload, new-tab, and unavailable-storage cases.
