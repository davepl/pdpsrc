CPU Complex

M8190 J-11

18 MHz bipolar bit-slice CPU with onboard FPP (FIS) and cache assist logic.

Memory

4 MB

M8367 + M8637 MSV11-J parity memory, 22-bit addressing, interleaved banks.

Bus + Timing

Q22

Q-bus backplane with adapters for mass storage; dual KDA50 pathing.

Kernel

BSD

Custom BSD kernel with tuned device drivers, Ethernet stack, and fast interrupt path.

Controller Stack

  • M7555 RQDX3 for MFM disks and dual RX50
  • Emulex UC07 SCSI bridging disk + tape to Q-bus
  • M8061 RL11 for dual RL02 drives (via MV11)
  • M7504 DEQNA Ethernet controller
  • M7165/M7164 KDA50 pair for RA8x/RA9x MSCP
  • M3104 DHV11-style serial mux for console and TTY lines

Storage & Media

  • RA82 + dual RA92 on MSCP via KDA50
  • MFM hard disk on RQDX3 for bootstrap and swap
  • RX50 dual floppies for field media
  • RL02 pair on RL11 for legacy images
  • TKZ50 DLT via UC07 for backups
  • Termcap, swap, and paging tuned for 4 MB window

Networking & Services

  • DEQNA Ethernet with tuned BSD if_qe driver
  • rsh/telnet for console access; TTY served by M3104
  • NFS exports from MSCP volumes; UUCP dial-in possible
  • Custom HTTP server (this page) built for low IRQ latency

Architecture Notes

  • FIS-enabled J-11 implements full PDP-11 ISA with EIS
  • 22-bit memory management, SPL-aware drivers
  • MSCP storage for uniform disk/tape presentation
  • Console ODT present; boot via DL offline and netboot capable
  • Backplane wiring balanced for DMA (KDA50 + DEQNA)
