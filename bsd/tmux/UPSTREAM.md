The upstream directory retains the original source licenses. Changes for the
port are made in those files, with the 2.11BSD adaptations in native/. The
initial runtime target is one session with two 80-column windows and
detach/reattach.

LICENSE.md lists every body of code in this port, its owners and its terms,
including the compatibility files tmux ships and the three build-tool files
taken from 2.11BSD.
